# 🎹 Gesture Synth (bôa - duvet Edition)

เว็บแอปพลิเคชันเล่นคอร์ดซินธ์ด้วยการชูนิ้วหน้ากล้องเว็บแคม/กล้องมือถือ (Hand Tracking Gesture Synthesizer) ถอดแบบมาจากคลิปคัฟเวอร์เพลง **bôa - duvet**

## ✨ ฟีเจอร์หลัก
- **ตรวจจับนิ้วมือแบบเรียลไทม์ (MediaPipe Hands):** ชูนิ้ว 1 ถึง 7 นิ้ว (ใช้มือเดียวหรือสองมือรวมกันได้) เพื่อเล่นคอร์ด `I`, `ii`, `iii`, `IV`, `V`, `vi`, `vii°` ในคีย์ E Major
- **รองรับทุกแพลตฟอร์ม 100% (Cross-Platform Native Web Audio):** ใช้ระบบสังเคราะห์เสียงของเบราว์เซอร์โดยตรง พร้อมระบบปลดล็อกเสียงสำหรับ iOS (Safari), Android (Chrome), Windows และ macOS
- **โหมดสำรองครบครัน:** สามารถแตะปุ่มคอร์ดบนหน้าจอมือถือ หรือกดปุ่มตัวเลข `1-7` บนคีย์บอร์ดเพื่อเล่นได้ทันทีแม้ไม่เปิดกล้อง

## 🚀 วิธีใช้งานบน GitHub Pages
1. อัปโหลดไฟล์ `index.html` และ `README.md` ขึ้นไปที่ Repository บน GitHub ของคุณ
2. ไปที่แถบ **Settings** > เมนู **Pages** (ด้านซ้าย)
3. ในหัวข้อ **Build and deployment** > **Branch** ให้เลือกเป็น `main` (หรือ `master`) แล้วกด **Save**
4. รอประมาณ 1-2 นาที จะได้ลิงก์เว็บไซต์ `https://<ชื่อผู้ใช้ของคุณ>.github.io/<ชื่อ-repo>/` สามารถเปิดเล่นได้ทั้งบนมือถือและคอมพิวเตอร์!
